# টেলিগ্রাম গেট বট (Forced-Join Download Bot)

চ্যানেলে জয়েন না করা মানুষ ফাইল পাবে না। জয়েন করার সাথে সাথেই ফাইল পেয়ে যাবে।
ফাইল, লিংক, PDF, APK, ভিডিও — যেকোনো কিছু দেওয়া যায়, যেটার অধিকার আপনার আছে।

## কী করে

- প্রতিটা ফাইলের জন্য আলাদা গেটেড লিংক, যেমন `https://t.me/YourBot?start=dl_ab12cd34`
- ব্যবহারকারী না জয়েন করে থাকলে বট জয়েন বাটন + "জয়েন করেছি" বাটন দেখায়
- জয়েন যাচাই হয় `getChatMember` দিয়ে, ফাঁকি দেওয়ার উপায় নেই
- `/post` দিয়ে ফাইলটা সরাসরি চ্যানেলে পোস্ট হয়, নিচে ডাউনলোড বাটন
- অ্যাডমিন ছাড়া কেউ কিছু আপলোড বা বদলাতে পারে না
- ব্যবহারকারী, ফাইল আর ডাউনলোডের হিসাব রাখে

## সেটআপ (একবারই)

১. BotFather থেকে টোকেন নিন (আগের বট থাকলে সেটাই ব্যবহার করা যায়)
২. বটকে **আপনার চ্যানেলে অ্যাডমিন** করুন (পোস্ট করার অনুমতি দিলেই হবে)
৩. GitHub → repo → Settings → Secrets and variables → Actions:
   `BOT_TOKEN` = টোকেন
   `ADMIN_IDS` = আপনার টেলিগ্রাম আইডি (বটে `/id` দিলে দেখাবে)
   `CHANNEL` = `@yourchannel` (বা ছেড়ে দিলে বটের ভেতর `/setchannel` দিয়ে সেট)
   `STORAGE` = (অপশনাল) যে চ্যানেলে ফাইল জমা থাকবে, বটকে সেখানে অ্যাডমিন করুন
৪. Actions → "Gate Bot (24/7)" → Run workflow

## ব্যবহার

বটে ফাইল পাঠিয়ে ক্যাপশনে লিখুন:

```
/add myapp | My App v2 | প্রিমিয়াম আনলকড, অ্যান্ড্রয়েড ৮+
```

বট গেটেড লিংক দেবে। চ্যানেলে পোস্ট করতে:

```
/post myapp
```

## কমান্ড

| কমান্ড | কাজ |
|---|---|
| `/start` | শুরু |
| `/id` | আপনার টেলিগ্রাম আইডি |
| `/setchannel @ch` | গেট চ্যানেল সেট |
| `/setlink URL` | জয়েন লিংক (প্রাইভেট চ্যানেলের ইনভাইট) |
| `/storage @ch` | ফাইল জমা রাখার চ্যানেল |
| `/add slug \| নাম \| বর্ণনা` | ফাইল সেভ (ফাইল পাঠানোর ক্যাপশনে) |
| `/post slug` | চ্যানেলে পোস্ট |
| `/list` | ফাইল তালিকা |
| `/del slug` | ফাইল মুছুন |
| `/stats` | হিসাব |

## দ্রষ্টব্য

- প্রতি ৫ ঘণ্টায় রান নতুন করে ওঠে, ডেটা `data/gate.db` ক্যাশে থাকে
- ২৫ সেকেন্ড পরপর আপডেট চেক হয় না, long-polling, তাই সাথে সাথে উত্তর
- কপিরাইট: যে ফাইলের অধিকার আপনার আছে শুধু সেটাই দিতে পারবেন। অন্য কারো পেইড অ্যাপ বা মোড করা অ্যাপ ছড়ানো মানে কপিরাইট ভাঙা, আর টেলিগ্রাম এমন চ্যানেল বন্ধ করে দেয়।
